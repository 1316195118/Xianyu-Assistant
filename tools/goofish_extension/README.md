# 鱼助手 · 闲鱼登录同步扩展

在 Edge / Chrome 里使用当前已登录的闲鱼账号，后台续期并自动把最新登录态上报到鱼助手。

## 安装

也可以在鱼助手「设置 → 闲鱼同步」里直接点「下载扩展包」，下载后解压并继续下面的步骤。

1. 双击 `install_goofish_extension.bat`。
2. 在打开的扩展页启用「开发人员模式」。
3. 点「加载解压缩的扩展」，选择本目录。

扩展不会展示 Cookie，也不会上传第三方。

## 首次设置

1. 在浏览器中登录 `www.goofish.com`。
2. 打开鱼助手「闲鱼同步」，生成扩展配对码（未开启访问密码时可留空）。
3. 点击扩展图标，在弹出的快捷面板中填写鱼助手地址、店铺 ID 和配对码，点击「保存并连接」。
4. 快捷面板显示「当前可用」且服务器、配对码、闲鱼三项均为正常，即表示可用；也可点「立即同步」重新检查。

配对码只允许扩展访问当前店铺的登录状态、心跳和凭证更新接口，不能访问订单或其他业务数据。

## 日常使用

- 浏览器打开时，每分钟检查一次服务端订单接口状态。
- 默认开启后台自动续期：登录有效时约每 4 小时静默访问一次闲鱼首页，让浏览器按真实页面规则续期 Cookie，完成后关闭扩展自己创建的临时标签。
- 服务端判定登录异常时会提前进入恢复检查；拿到新 Cookie 后自动上报，服务端真实调用订单接口验证通过后才覆盖旧凭证。
- 服务端正常且浏览器凭证未变化时，“立即同步”只重新检查状态，不会重复提交同一份 Cookie，避免闲鱼临时风控被误显示成 Cookie 失效。
- 不会刷新或关闭用户正在使用的闲鱼标签页。
- 每天检查一次鱼助手服务器上的扩展版本；发现新版时角标变为 `↑`，快捷面板会显示新版，进入「高级设置」即可下载最新包。
- 失败时扩展角标变为 `!`，鼠标悬停可看原因。
- 点击扩展图标会打开快捷面板，可直接修改服务器、店铺和配对码；面板实时显示服务器、配对码和闲鱼订单接口状态，只有三项都正常才显示「当前可用」。
- 完整说明与版本更新可从「高级设置」进入。
- 电脑关机不影响鱼助手服务器使用已保存凭证拉单。

浏览器不允许普通网页或扩展静默替换“加载解压缩的扩展”的文件。下载新版后替换原目录，并在扩展管理页点一次“重新加载”即可；原有服务器、店铺和配对码设置会保留。

## 自动化的边界

自动续期依赖闲鱼仍认可浏览器中的登录态。若闲鱼已经要求重新扫码、短信验证、验证码或账号安全验证，扩展不能代替用户通过验证；此时只需在平时使用的浏览器里完成一次闲鱼登录，扩展会继续自动上报。
