# 鱼助手 · 闲鱼登录同步扩展

在 Edge / Chrome 里使用当前已登录的闲鱼账号，自动把最新登录态上报到鱼助手。

## 安装

1. 双击 `install_goofish_extension.bat`。
2. 在打开的扩展页启用「开发人员模式」。
3. 点「加载解压缩的扩展」，选择本目录。

扩展只在当前浏览器登录 Cookie 发生变化或服务端登录态失效时上报；不会展示 Cookie，也不会上传第三方。

## 首次设置

1. 在浏览器中登录 `www.goofish.com`。
2. 打开鱼助手「闲鱼同步」，生成扩展配对码（未开启访问密码时可留空）。
3. 点击扩展图标，填写鱼助手地址、店铺 ID 和配对码，点击「保存并授权」。
4. 再点一次「立即检查并上报」，看到绿色 ✓ 即表示成功。

配对码只允许扩展访问当前店铺的登录状态、心跳和凭证更新接口，不能访问订单或其他业务数据。

## 日常使用

- 浏览器打开时，每分钟检查一次服务端订单接口状态。
- 闲鱼登录态发生变化时自动上报，服务端真实调用订单接口验证通过后才覆盖旧凭证。
- 失败时扩展角标变为 `!`，鼠标悬停可看原因。
- 电脑关机不影响鱼助手服务器使用已保存凭证拉单。
