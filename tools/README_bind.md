# 闲鱼登录自动同步

鱼助手使用自己的服务器拉订单。浏览器扩展负责在你平时登录闲鱼的 Edge / Chrome 中后台续期登录态，Cookie 变化后自动把最新凭证上报到鱼助手，并由服务器真实调用订单接口验证。

不需要专用浏览器窗口，不需要托盘程序，也不要求电脑 24 小时开机。

## 推荐方案：浏览器扩展

扩展目录：[`goofish_extension`](goofish_extension/README.md)

鱼助手网页「设置 → 闲鱼同步」现可直接下载扩展包，不需要在部署目录里手动查找源码。

1. 双击 `goofish_extension/install_goofish_extension.bat`。
2. 在打开的 Edge 扩展页启用「开发人员模式」，点「加载解压缩的扩展」，选择 `goofish_extension` 目录。
3. 点击扩展图标，在快捷面板中填写鱼助手地址和店铺 ID；更多选项可点「高级设置」。
4. 如果鱼助手开启了访问密码，在「设置 → 闲鱼同步 → 浏览器扩展设置」生成配对码并填入扩展；未开启访问密码时可留空。
5. 点击「保存并连接」。
6. 点击「打开官方扫码登录」。扩展会在当前浏览器打开闲鱼官方登录页，用闲鱼 App 扫码并确认。
7. 扩展检测到登录完成后会自动上报；快捷面板显示「当前可用」且服务器、配对码、闲鱼三项正常，即表示可用。

之后扩展每分钟检查一次服务端状态；默认约每 4 小时在后台访问一次闲鱼首页续期登录态，只有相关 Cookie 变化才会上报。扩展不会刷新当前正在使用的闲鱼标签。失败时角标变为 `!`，鼠标移到扩展图标即可看到原因。

服务端已经正常且浏览器凭证没有变化时，「立即同步」只重新检查连接，不会重复提交同一份 Cookie，避免闲鱼临时风控被误显示成登录失效。

扩展还会每天检查鱼助手服务器上的最新插件版本。发现新版时角标变为 `↑`，快捷面板会显示新版，进入「高级设置」即可下载；替换解压目录后在浏览器扩展页点一次“重新加载”，原有配置会保留。

如果闲鱼明确要求重新扫码、短信验证或验证码，自动续期无法越过账号安全验证；点击扩展里的「打开官方扫码登录」，在闲鱼官方页面完成验证后，后续自动上传会自行恢复。

## 配对码与安全

- 配对码按店铺生成，数据库只保存哈希，生成时显示一次。
- 配对码只允许扩展访问当前店铺的登录状态、心跳和凭证更新接口，不能读取订单、设置或其他业务数据。
- 重新生成配对码后，旧配对码立即失效；也可以随时在页面里撤销。
- 扩展不展示、不打印 Cookie，也不会把凭证发送到鱼助手以外的地址。
- 服务器收到凭证后先调用真实订单接口校验，校验失败不会覆盖原有登录态。

## 备用方案：一次性绑定工具

不能使用浏览器扩展的环境，可以双击 `goofish_bind.bat`，按提示选择服务器和店铺，在打开的浏览器中登录一次。绑定完成后工具会退出，不需要保持窗口常开。

命令行方式：

```bat
node goofish_bind.js --server http://192.168.1.10:18083 --shop 1
```

这个方案保存的是当次登录凭证；后续登录态变化仍建议改用浏览器扩展自动更新。

## 正式扫码入口与实验性备用

正式入口是在扩展内打开闲鱼官方登录页，由日常浏览器按真实页面规则生成二维码。扫码完成后，扩展检测 `cookie2`、`unb` 等认证 Cookie 更新，再自动上报并校验。

鱼助手网页里的服务器二维码保留为实验性备用功能。闲鱼扫码接口会校验浏览器环境和设备指纹，服务器端即使拿到同样的参数，也可能被判为环境异常并返回 `EXPIRED`。

## 登录态说明

鱼助手会把闲鱼 Cookie 和淘宝 / 天猫 SSO Cookie 一起保存。淘宝 SSO 可以检查部分短期会话并刷新 `_m_h5_tk` 等签名令牌，但不能把已经失效的闲鱼 H5 登录 `cookie2` 凭空换回来。

电脑关机期间服务器仍可使用最后一次验证通过的凭证拉单。如果登录在关机期间失效，下次打开浏览器时扩展会自动检查；检测到登录态变化后重新验证并上报。

## 常见问题

**扩展显示「需要配对码」**：到鱼助手「设置 → 闲鱼同步 → 浏览器扩展设置」生成，填进扩展快捷面板后保存。

**扩展显示 `!`**：把鼠标移到扩展图标看原因。若是未登录，点击快捷面板里的「打开官方扫码登录」；若是配对码失效，重新生成并填入。

**快捷面板显示「部分可用」**：看服务器、配对码、闲鱼三项中哪一项异常。服务器已连接但闲鱼失效时，点击「打开官方扫码登录」；配对码异常时重新生成并填入快捷面板。

**浏览器扩展显示离线**：电脑关机或浏览器关闭时可以忽略，服务器仍能拉单；下次打开浏览器会自动恢复。

**连不上鱼助手**：确认地址和端口对、服务器可访问。局域网使用内网 IP，公网部署使用 HTTPS 地址。

**不想一直开着浏览器**：不需要。扩展只在浏览器运行时负责更新登录态，订单拉取和自动同步都在服务器完成。
