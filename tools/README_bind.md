# 闲鱼一键绑定工具（给其他部署 / 其他玩家）

真浏览器扫码登录 → 自动收 Cookie 绑定到你自己的记账服务器。**不用手动复制 Cookie、不用改代码。**

## 为什么必须用你自己的电脑跑

闲鱼的风控校验的是「整套设备环境是否同源」。二维码必须在**真实浏览器**里生成、手机扫码也由真浏览器完成，闲鱼才认。所以这个工具跑在你电脑上（开一个专用浏览器窗口），服务器只在最后接收 Cookie。

> 服务器端直接生成二维码会返回 `EXPIRED`——因为 token 是真的、但生成环境（机房 IP、伪造指纹）是假的。这条死路已验证，不用再试。

## 环境要求

- Windows / macOS / Linux 均可
- **Node.js 18+**（内置 fetch / WebSocket），到 https://nodejs.org 装 LTS 版
- 本机装有 **Microsoft Edge** 或 **Google Chrome**（工具会自动找）

## 使用步骤

1. 把整个 `tools` 目录拷到你电脑上（需要 `goofish_bind.js` 和 `goofish_bind.bat`）
2. 双击 `goofish_bind.bat`
3. **第一次运行**：按提示输入你的记账服务器地址（如 `http://192.168.1.10:18083`），会自动存到同目录 `config.json`，以后不用再填
4. **选店铺**：工具自动列出服务器上所有店铺，输入序号选择；想跳过交互可在命令行加 `--shop 店铺ID`
5. 弹出专用浏览器窗口（闲鱼登录页）→ 手机闲鱼扫码 → 手机点确认
6. 看到「✓ 绑定成功」即完成，窗口自动关闭

## 命令行参数（可选，双击时一般不用）

```bat
node goofish_bind.js --server http://192.168.1.10:18083 --shop 3
```

- `--server`：指定服务器地址（覆盖 config.json）
- `--shop`：指定店铺 ID（跳过选择交互）

## 关于选店铺 / 多账号

- 工具启动时从 `GET /api/shops` 自动拉取店铺列表（含名称、ID），所以**你服务器上有哪些店铺、叫什么名字，工具里就显示哪些**
- 每个店铺用**独立的浏览器 profile**（`profiles/shop-<id>/`），互不串号。你的闲鱼小号、大号可以分别绑到不同店铺，各自保持登录态
- 同一店铺重复绑定：会话还在就直接成功（不用再扫）；掉了才需要重新扫

## 关于自动续期

绑定时工具会把闲鱼 Cookie + 淘宝 SSO Cookie 一起存到服务器。之后每次同步前服务器会用淘宝 SSO 静默换发闲鱼会话，**一般几个月才需要重新扫一次**。淘宝 SSO 没拿到也不影响本次使用，只是过期后要重新绑定。

## 数据与安全

- Cookie 只在你电脑和**你自己指定的服务器**之间传递，不回显、不上传任何第三方
- 浏览器用独立 profile，不动你日常用的浏览器数据
- `config.json` 只存服务器地址，无敏感信息

## 常见问题

**连不上服务器**：确认地址对、服务在运行。局域网用内网 IP，公网部署用公网地址，注意端口。

**找不到浏览器**：装 Edge 或 Chrome；或把浏览器路径加到脚本顶部的 `CANDIDATES` 数组。

**需要 Node.js**：工具依赖 Node 18+ 的内置 fetch/WebSocket。装好后重新双击。

**扫码后没反应**：确认在手机闲鱼 App 里扫（不是微信/浏览器），并在手机上点了「确认登录」。
