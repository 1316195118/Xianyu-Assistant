# 闲鱼登录自动同步

鱼助手使用自己的服务器拉订单。浏览器扩展只负责一件小事：在你平时登录闲鱼的 Edge / Chrome 中，发现登录 Cookie 变化时自动把最新凭证上报到鱼助手，并由服务器真实调用订单接口验证。

不需要专用浏览器窗口，不需要托盘程序，也不要求电脑 24 小时开机。

## 推荐方案：浏览器扩展

扩展目录：[`goofish_extension`](goofish_extension/README.md)

1. 双击 `goofish_extension/install_goofish_extension.bat`。
2. 在打开的 Edge 扩展页启用「开发人员模式」，点「加载解压缩的扩展」，选择 `goofish_extension` 目录。
3. 在当前浏览器打开 `www.goofish.com` 并完成登录。
4. 点击扩展图标，填写鱼助手地址和店铺 ID。
5. 如果鱼助手开启了访问密码，在「设置 → 闲鱼同步 → 浏览器扩展设置」生成配对码并填入扩展；未开启访问密码时可留空。
6. 点击「保存并授权」，再点「立即检查并上报」。扩展角标显示绿色 `✓` 即表示成功。

之后扩展每分钟检查一次服务端状态；只有闲鱼登录态相关 Cookie 变化才会上报。失败时角标变为 `!`，鼠标移到扩展图标即可看到原因。

## 配对码与安全

- 配对码按店铺生成，数据库只保存哈希，生成时显示一次。
- 配对码只允许扩展访问当前店铺的登录状态、心跳和凭证更新接口，不能读取订单、设置或其他业务数据。
- 重新生成配对码后，旧配对码立即失效；也可以随时在页面里撤销。
- 扩展不展示、不打印 Cookie，也不会把凭证发送到鱼助手以外的地址。
- 服务器收到凭证后先调用真实订单接口校验，校验失败不会覆盖原有登录态。

## 备用方案：一次性绑定工具

不能使用浏览器扩展的环境，可以双击 `goofish_bind.bat`，按提示选择服务器和店铺，在打开的浏览器中登录一次。绑定完成后工具会退出，不需要保持窗口常开。

命令行方式：

```bat
node goofish_bind.js --server http://192.168.1.10:18083 --shop 1
```

这个方案保存的是当次登录凭证；后续登录态变化仍建议改用浏览器扩展自动更新。

## 为什么服务器不能直接扫码

闲鱼扫码接口要求二维码在真实浏览器环境中生成，并带页面 JavaScript 实时计算的设备指纹。服务器端即使拿到同样的接口参数，也会被闲鱼判为环境异常并返回 `EXPIRED`。因此二维码要由本机浏览器生成；扩展直接复用这个真实登录环境，最省事也最稳定。

## 登录态说明

鱼助手会把闲鱼 Cookie 和淘宝 / 天猫 SSO Cookie 一起保存。淘宝 SSO 可以检查部分短期会话并刷新 `_m_h5_tk` 等签名令牌，但不能把已经失效的闲鱼 H5 登录 `cookie2` 凭空换回来。

电脑关机期间服务器仍可使用最后一次验证通过的凭证拉单。如果登录在关机期间失效，下次打开浏览器时扩展会自动检查；检测到登录态变化后重新验证并上报。

## 常见问题

**扩展显示「需要配对码」**：到鱼助手「设置 → 闲鱼同步 → 浏览器扩展设置」生成，填进扩展设置页后保存。

**扩展显示 `!`**：把鼠标移到扩展图标看原因。若是未登录，先在当前浏览器完成闲鱼登录；若是配对码失效，重新生成并填入。

**浏览器扩展显示离线**：电脑关机或浏览器关闭时可以忽略，服务器仍能拉单；下次打开浏览器会自动恢复。

**连不上鱼助手**：确认地址和端口对、服务器可访问。局域网使用内网 IP，公网部署使用 HTTPS 地址。

**不想一直开着浏览器**：不需要。扩展只在浏览器运行时负责更新登录态，订单拉取和自动同步都在服务器完成。
