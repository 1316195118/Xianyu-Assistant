# 鱼助手上线检查清单

对照文章的四阶段清单，本项目按“自托管经营账本”的实际范围落实。

## 合规与安全

- [x] 提供 `/privacy` 隐私政策和页脚入口。
- [x] 提供 `/terms` 服务条款和页脚入口。
- [x] 前端无硬编码真实 API Key；`.env` 默认忽略；OCR 请求走后端代理。
- [ ] HTTPS 强制跳转与 HSTS 由实际部署的反向代理/隧道配置；当前 Go 服务输出基础安全头。
- [x] 当前没有广告、统计或营销脚本，不加载非必要 Cookie；使用统计 SDK 的二次部署必须补同意机制。

## SEO 与传播

- [x] 主要页面有唯一标题、描述、canonical、Open Graph 和 Twitter Card。
- [x] 提供 1200×630 社交预览图。
- [x] 提供 ICO、SVG favicon、Apple Touch Icon 和 Web App Manifest。
- [x] 提供动态 `/sitemap.xml` 和 `/robots.txt`，屏蔽 `/api/` 与下载目录。
- [x] 检查并补充运行时 `<img>` 的描述性 alt、尺寸和首屏以下懒加载。

## 性能与体验

- [x] 提供 `tools/optimize_images.py`，扫描大图并转 WebP，默认只预览。
- [x] 首屏只加载概览；其余视图在导航悬停/聚焦时预取，不再空闲预取全部分包。
- [x] 清理低对比度占位符、焦点边框和品牌文字色。
- [x] 使用 375px、390px、768px 视口检查核心页面横向溢出和触控尺寸。
- [x] 未知前端路径显示品牌 404 页面，并返回真实 HTTP 404。

## 健壮性与增长

- [x] 检查公开页面内部链接、隐私/条款入口和主要导航。
- [x] 登录和录单表单已有提交中禁用、前端提示与后端校验。
- [x] 应用没有公开联系/评论/订阅表单，不接入验证码或垃圾提交防护。
- [x] 默认不接入分析工具；这是隐私优先选择，如需加装必须自行征得同意并更新政策。
- [x] 登录页首屏说明“每一单到底赚多少，打开就算清”，并提供具体进入账本 CTA。

## 发布前手工确认

- 在实际域名确认 HTTPS、HSTS、反向代理和防火墙。
- 确认备份目录可恢复，并至少保留一份异地备份。
- 在真实手机和实际店铺数据上检查微信内置浏览器、软键盘和底部安全区。
- 若面向商业客户或跨境用户，请让当地法务审阅隐私政策和服务条款。
